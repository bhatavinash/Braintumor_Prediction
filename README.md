
### Brain Tumor Prediction Using Deep Learning

- Developed a CNN-based brain tumor prediction system using the **ResNet-152 architecture**.
- Trained the deep learning model to analyze and classify brain MRI images for tumor prediction.
- Integrated the trained model into a **Django web application**, handling image uploads, backend processing, and prediction results.
- Built an interactive web interface to enable users to upload MRI scans and view prediction outcomes.

**Tech Stack:** Python, TensorFlow/Keras, CNN, ResNet, Django, HTML, CSS, JavaScript.
